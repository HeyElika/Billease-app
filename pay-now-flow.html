Pay Now, entered from a loan

The loan the user tapped stays the primary repayment item, already included and sitting at the top. Everything else (other active loans, Credit Line) is offered below as an optional add-on that the user has to switch on deliberately. The total in the action bar recalculates on every change.

Total payment behavior

The action bar is the single place the running total lives. With nothing selected the button carries no figure, matching the Figma default view. As soon as one item is included the button switches to the amount form and keeps recalculating.

Interaction logic

Preserving the original intent

  • The loan the user came from renders first, already expanded, with Pay next installment preselected.
  • It is the only item with a selection on entry, so the default total is that loan's next installment.
  • It can still be changed to full balance, a custom amount, or Don't include, so nothing is forced.

Additional items stay opt-in

  • Other loans and Credit Line sit under Include other payments?, collapsed, with no radio selected.
  • Collapsed means zero contribution to the total. Expanding alone adds nothing either.
  • An amount is only added once the user picks a specific row, which is the conscious choice.

Credit Line is never silent

  • Credit Line is listed first among the optional items, ahead of other loans, matching the Figma order.
  • It carries its own due line (Due in 4 days) while collapsed, so an outstanding amount is visible without expanding.
  • Expanding reveals statement balance, full balance, minimum due with its interest caveat, and custom amount.

Staying fast

  • One screen. No separate selection flow, no re-picking the loan the user just came from.
  • Add-ons are collapsed by default, so the screen opens short and the primary item dominates.
  • The total lives in the button the user is already heading for, so no extra review step is needed.

Notes and open points

  • Amounts are the ones in the Figma frames. The three add up to ₱1,234.56, which is the figure on the QRPh screen and the loans dashboard in the same file.
  • MOMENTO COFFEE01 is a placeholder in Figma with no amounts on its collapsed card, so its expanded rows reuse the per-loan amounts Figma defines for a loan card.
  • Custom amount contributes ₱0.00 here. The amount entry screen is not in the supplied frames, so it was not built. AmountInput.jsx is the component for it.
  • Order of the optional items follows Figma (Credit Line, then other loans), not the order in the brief.
